# Preguntas sobrre la prueba tecnica

1. ¿Cuál es la fuente de verdad del precio de un combo y cómo se valida que el descuento aplicado sea correcto?

2. ¿Cómo se determina cuántas veces se aplica un combo cuando el carrito contiene varias unidades de los productos requeridos?

3. Si varios combos usan los mismos productos, ¿qué regla define cuál se aplica primero y cómo se evita que una misma unidad reciba más de un beneficio?

4. ¿Cómo se distribuye el descuento del combo entre las líneas de productos para calcular correctamente la base gravable de cada una?

5. Si cambian los precios, descuentos o impuestos después de cotizar, ¿la confirmación debe conservar los valores de la cotización o recalcular el pedido?
